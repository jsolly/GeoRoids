# GeoRoids HUD Treatment (retro vector)

## Kill

- Giant top-center score
- Yellow DEBUG MODE as production aesthetic
- Laser bloom / huge bright beams
- “Game Server” (or similar) under radar
- Dense opaque / filled leaderboard panels
- Any glass / frosted / glossy HUD chrome

## Keep / rework

| Element | Treatment |
| --------- | ----------- |
| Lives | Tiny outline ship glyphs in local `#5EEAD4` |
| Score | Small phosphor text `#E2E8F0` top-left or under lives |
| Leaderboard | Sparse translucent list; remote `#7DD3FC` / local `#5EEAD4` |
| Radar | Hairline muted ring `#64748B`; pin-dot contacts; amber hairline three-tongue campfire for furnaces; no server label |
| Universe map | Same fire ink; zoomed-out amber flame pin, nearby/close three-tongue campfire |
| Health | Thin tick or ~2px capsule `#4ADE80`; no always-on `100/100` |
| Alerts | `#F43F5E` sparingly |

## Principle

In play, HUD is quieter than the smallest vector ship. Title screens may use `accent_ui` `#A78BFA` — still outline DNA.
